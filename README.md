# 누대시 (Nudaesi)
> **누가 대신 시간표 짜줬으면 좋겠다: 대학생 맞춤형 수강신청 자동 설계 솔루션**

![Python](https://img.shields.io/badge/Python-3.x-blue.svg) ![CustomTkinter](https://img.shields.io/badge/GUI-CustomTkinter-green.svg) ![Matplotlib](https://img.shields.io/badge/Visualization-Matplotlib-orange.svg)

## 프로젝트 개요 (Overview)
**누대시**는 매 학기 반복되는 대학생들의 수강신청 전쟁을 해결하기 위해 개발된 **Python 기반 자동 시간표 설계 프로그램**입니다.
단순히 시간표를 조합하는 것을 넘어, **캠퍼스 건물 간 이동 거리, 학점 제한, 공강 확보** 등 현실적인 제약 조건을 모두 고려하여 이수가 가능한 최적의 시간표를 도출합니다.

### 개발 배경 (Background)
1.  **복잡한 연산:** 수작업 시 시간 충돌 확인 및 건물 간 이동 가능 여부(도보 시간)를 계산하기 어려움.
2.  **휴먼 에러:** 실수로 필수 과목을 누락하거나, 이동이 불가능한 동선을 짜는 문제 발생.
3.  **최적화 니즈:** 공강, 점심시간 확보 등 삶의 질을 높이는 시간표에 대한 수요 증가.

## 핵심 기능 (Key Features)

### 1. 맞춤형 시간표 자동 완성
* **원클릭 자동 추천:** 듣고 싶은 강의(메인/후보)를 입력하고 **실행** 버튼만 누르면, 시간 충돌 없이 이수 가능한 모든 시간표 조합을 찾아냅니다.
* **유연한 후보 관리:** 각 행에 여러 후보 강의를 입력해두고, **On 체크박스**로 원하는 강의만 활성화하여 다양한 경우의 수를 계산할 수 있습니다.
* **우선순위 반영:** '공강 확보', '이동 거리 최소화', '특정 시간대 선호' 등 나의 라이프스타일에 맞는 최적의 시간표를 1순위로 추천합니다.

### 2. 이동 시간 & 공강 정밀 분석
* **건물 간 거리 계산:** 학교 맵 데이터를 기반으로 강의실 간 실제 도보 이동 시간을 계산합니다.
* **직관적인 신호등 알림:** 이동 시간이 여유로우면 **회색**, 빠듯하면 **주황색**, 물리적으로 불가능하면 **빨간색** 그래프로 표시하여 위험성을 즉시 알려줍니다.
* **충돌 감지:** 수업 시간이 1분이라도 겹치면 **[충돌]** 경고를 띄워 실수를 방지합니다.

### 3. 나만의 시간표 검증 (평가 모드)
* **직접 짜보기:** 자동 추천을 받지 않고, 내가 미리 짜둔 시간표가 현실적인지 검증하고 싶을 때 사용합니다.
* **실시간 피드백:** 슬롯에서 강의를 하나씩 직접 선택하면, 학점 초과 여부와 이동 동선을 즉시 분석해 피드백을 제공합니다.

### 4. 편리한 데이터 관리 & 저장
* **저장/불러오기:** 힘들게 입력한 강의 정보를 날리지 않도록 **JSON 파일**로 저장하고 언제든 다시 로드할 수 있습니다.
* **그래프 이미지 저장:** 완성된 시간표는 **PNG 이미지**로 저장하여 갤러리에 보관하거나 친구들에게 공유할 수 있습니다.
* **다크 모드 UI:** 장시간 사용해도 눈이 편안한 `CustomTkinter` 기반의 직관적인 다크 모드 디자인을 적용했습니다.

## 시스템 아키텍처 (System Architecture)

본 프로젝트는 유지보수와 확장성을 위해 **MVC 패턴**을 차용하여 총 5개의 모듈로 분리 설계되었습니다.

| 모듈명 (File) | 역할 (Role) | 상세 설명 |
| :--- | :--- | :--- |
| **`main.py`** | **Controller** | 프로그램 진입점. UI 이벤트 처리 및 전체 흐름 제어, 방어적 코딩 적용 |
| **`models.py`** | **Model (Data)** | CSV 데이터 로드 및 시간 데이터 정수 변환(HH:MM → Minute) 처리 |
| **`logic.py`** | **Model (Algo)** | 핵심 알고리즘 엔진. 조합 생성, 유효성 검증, 가중치 점수 산정 수행 |
| **`visualizer.py`** | **View (Graph)** | `Matplotlib` 기반 그래프 생성 및 스캔라인 충돌 감지 시각화 |
| **`ui_components.py`** | **UI Helper** | `LectureTable`, `LectureCell` 등 반복되는 UI 컴포넌트 모듈화 및 1차 검증 |
